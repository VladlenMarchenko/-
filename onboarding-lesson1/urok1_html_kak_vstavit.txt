Как вставить интерактивный Урок 1 в Confluence

1. Создай/открой страницу: Онбординг → Урок 1. Введение в систему
2. Вставка → Другие макросы → HTML (или «HTML macro»)
3. Открой файл urok1_vvedenie_spr_rb.html
4. Скопируй ВСЁ содержимое файла (от <!DOCTYPE html> до </html>)
5. Вставь в тело макроса HTML → Сохранить → Опубликовать

Важно
- Макрос должен разрешать JavaScript (иначе пропадут прогресс, чеклист и квиз). Если после сохранения «мертвая» вёрстка без кликов — попроси админов Confluence разрешить script в HTML macro для пространства DATAFLOW.
- Внешних CDN нет — всё внутри файла, работает в корпсети.
- Прогресс и галочки доступов пишутся в localStorage браузера пользователя.
- Ссылки ведут на confluence.moscow.alfaintra.net — открываются из внутренней сети.

Если HTML-макрос ругается на размер
- Вставь только содержимое между <body>…</body> плюс объединённые <style> и <script> (без <html>/<head>), иногда так проходит лучше.
- Альтернатива: прикрепи .html вложением и на странице дай кнопку «скачать/открыть» + параллельно оставь wiki-версию urok1_vvedenie_spr_rb_confluence.txt

Рекомендуемая шапка страницы над макросом (wiki):
h1. Урок 1. Введение в систему
{info}Интерактивная версия ниже. Если макрос HTML недоступен на мобильном — используй текстовую копию на дочерней странице.{info}
